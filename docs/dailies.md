# Дейлики Fast Track

Формат LMS: **done** (что сделал) / **plan** (что дальше). Правила из урока «Стендапы и дейлики»: 3–5 пунктов, результаты, а не процессы, без «начать/продолжить». План — по приоритету, от ТОП-1. Проверка деливери: «что изменилось благодаря работе?»

## 06.10 — день 1

**done**
- Спроектировал сервис целиком до кода (API-first): 16 ADR, закрыты все 12 открытых вопросов брифа и все спорные места ТЗ (драйвер SQLite, валидация без zod, точность цен, Swagger UI, тестовая БД). На каждое решение — сравнение вариантов и обоснование.
- Утвердил контракт API v1 (OpenAPI 3.0, 16 операций): проходит Redocly lint, TS-типы генерируются. Web и тесты могут опираться на него с первого дня кода.
- Утвердил схему БД api и web (13 таблиц): все ограничения проверены на `node:sqlite` — 45 проверок, включая защиту от параллельных синхронизаций и идемпотентность повторной загрузки цен.
- Нашёл и закрыл на прототипах 13 рисков, которые проявились бы только в коде. Например: потеря точности цен уже в `JSON.parse`, `server.close()`, зависающий на SSE, несовместимость TypeScript 6 с кодогенерацией, `scryptSync` на 285 мс, блокирующий Event Loop.

**plan** (07.10, фаза B — сдаваемый `apps/api`)
1. Каркас монорепо с автоматическими проверками: lint, typecheck, тесты, контроль зависимостей по C7 — зелёные локально и в pre-commit.
