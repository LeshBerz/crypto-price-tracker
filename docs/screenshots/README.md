# Снимки экрана веб-клиента

Веб-клиент (`apps/web`) — дополнение сверх ТЗ. У сдаваемой версии интерфейса нет: её проверяют через Swagger UI (`/docs`).

**Как сняты.** Собранные Docker-образы (`docker compose --profile web up --build`), источник цен — стаб CoinMarketCap из репозитория с расширенным для съёмки списком монет, история за 30 дней дописана скриптом [`seed-price-history.ts`](../../apps/web/scripts/seed-price-history.ts). Настоящих котировок на снимках нет. Браузер — Chrome, размеры 1440 × 900 и 375 × 812 (телефон, плотность 2).

## Вход и временный пароль

Самостоятельной регистрации нет: учётную запись создаёт оператор и выдаёт временный пароль. С временным паролем доступен только экран его смены — BFF и поток событий отвечают 403 `password-change-required`.

| Вход | Обязательная смена временного пароля |
|---|---|
| ![Экран входа](login-desktop-light.png) | ![Экран смены временного пароля](password-change-desktop-light.png) |

## Дашборд

Цены приходят строкой и форматируются без перевода в число; ведущие нули мелкой монеты приглушены. Монета на паузе помечена, мини-график строится одним запросом на все монеты.

| Светлая тема | Тёмная тема |
|---|---|
| ![Дашборд, светлая тема](dashboard-desktop-light.png) | ![Дашборд, тёмная тема](dashboard-desktop-dark.png) |

## Линза точности

Нажатие на цену раскрывает строку из api целиком: цифры, скрытые округлением, подсвечены.

| Светлая тема | Тёмная тема |
