## Стаб и настоящий CoinMarketCap

Стаб — небольшой HTTP-сервер из этого репозитория ([`apps/api/scripts/cmc-stub.ts`](../../apps/api/scripts/cmc-stub.ts)), который отвечает как CoinMarketCap. Он же используется в тестах.

| | Стаб | Настоящий CoinMarketCap |
|---|---|---|
| Ключ CMC и интернет | не нужны | нужны |
| Монеты | BTC, ETH, MEME; остальные символы — 422 | любые, которые знает CMC |
| Цены | неизменные | живые, обновляются раз в 60 секунд |
| Квота | не тратится | 1 кредит на синхронизацию всего списка, плюс проверка символа при добавлении монеты |

Источник выбирает переменная `CMC_BASE_URL`. Значение по умолчанию зависит от способа запуска:

| Способ запуска | `CMC_BASE_URL` не задана | Как переключить |
|---|---|---|
| `docker compose up` | стаб | `CMC_BASE_URL=https://pro-api.coinmarketcap.com` |
| `npm run dev -w @cpt/api` | настоящий CoinMarketCap | `CMC_BASE_URL=http://localhost:4010` и запущенный стаб |
