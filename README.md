# Crypto Price Tracker

Backend-сервис для отслеживания и агрегации цен криптовалют через CoinMarketCap API.
Тестовое задание Evercode Lab Fast Track (Backend, Node.js).

> Статус: 🚧 в разработке — прогресс в [ROADMAP.md](ROADMAP.md)

## Стек
Node.js · TypeScript · Express · SQLite (raw SQL) · axios · Jest + Supertest · Swagger (OpenAPI 3.0) · Docker
